The "New payment" method grid: rounded glass tiles with an icon and caption, three columns by default. The canonical zk.money layout is Send / Receive / Link, Scan / Bank / Email, Card / Deposit / Withdraw, with unavailable methods marked `disabled` (dimmed, non-tappable).

Keep it near phone width so tiles stay square-ish; each method takes `label`, `icon`, and an `onClick`.
