Initial avatar with a fixed purple-to-blue disc, an outer story ring, and an optional top-right notification dot. The ring is `unviewedRingColor` (default gold; the Home top bar uses #A000FF) while `hasUnviewedStory` is true, white once viewed.

Use in the Home top bar and anywhere story/notification state matters. For plain identity avatars with per-contact gradients use `GradientInitialAvatar`.
