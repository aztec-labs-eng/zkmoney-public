Payment-method picker row: leading slot (typically an `IconCircle`), gradient title over a muted subtitle, trailing chrome (`RowChevron`). `disabled` drops the gradient and dims both lines to #565656; pair it with `floatingTrailing` and a `ComingSoonPill` so the badge floats top-right and the subtitle keeps full width.

Rows are not buttons themselves; wrap them or handle taps in the parent.
