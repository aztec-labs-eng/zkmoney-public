Contact list row: deterministic gradient initial avatar, gradient title, muted subtitle, trailing chevron. Pass a bare or `@`-prefixed handle for L2 contacts (title becomes `@handle`, subtitle "zk.money"). For L1 wallets set `isL1`: with a real `name` the label becomes the title and the address the subtitle; unlabeled (or `name="External Wallet"`) shows the truncated address with an "Ethereum wallet" subtitle.

The same `tag` always yields the same avatar gradient, keeping identity consistent across screens.
