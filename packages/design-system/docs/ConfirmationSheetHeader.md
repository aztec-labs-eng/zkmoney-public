The header row of a confirmation sheet: a Sen 20 semibold title held at true center, with a 40px glass-circle back button at the left when `onClose` is given. Omit `onClose` to hide the button without shifting the title. Usually you get this for free from `ConfirmationSheetShell`; use it directly only when building custom sheet layouts.
