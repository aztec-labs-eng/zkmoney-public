Home-screen row of equal-width quick-action tiles: a 70.5px rounded glass tile with a centered white icon and a secondary-color caption below. Pass 3-4 `actions` ({ title, icon, onClick }); tiles share the row width equally.

Use only on the home screen directly under the balance header; typical actions are Send, Scan, Add funds, Withdraw. For nav-bar icon actions use `TopNavIconButton` instead.
