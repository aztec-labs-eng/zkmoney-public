40x40 liquid-glass circle (white @ 3% fill, backdrop blur, soft shadow) hosting arbitrary children, usually a white `Icon`. With `onClick` it renders as a button; without it, as decorative chrome.

The base primitive behind `TopNavIconButton`; use it directly for custom glyphs, non-default sizes, or decorative circles. For the brighter fill used in settings-row icons, use `IconCircle`.
