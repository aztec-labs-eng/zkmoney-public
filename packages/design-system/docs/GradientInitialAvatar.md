Gradient circle avatar with a centered uppercase initial taken from `name`. Omit `colors` to derive a deterministic gradient pair from the name (same handle, same gradient everywhere); set `ringed` for the white "story" ring used on the current user.

The default identity avatar across contact rows (44), amount cards (32), and profile heroes (64-96). For the gold/purple story-ring treatment with a notification dot, use `StoryRingAvatar` instead.
