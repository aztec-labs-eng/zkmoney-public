The primary CTA — a full-width 56px capsule. Use `buttonStyle="gradient"` (default) for the single most important action on a screen and `buttonStyle="dark"` for the secondary/dismiss action stacked under it (e.g. "Keep waiting" under a destructive confirm); the dark variant is a liquid-glass capsule that frosts and refracts the content behind it, so place it over real content rather than a flat fill. Set `isLoading` while a transaction is proving; the label hides and a white spinner shows. Use `trailingIcon="arrow-right"` on onboarding/continue flows.

One gradient button per screen. Pair with `DestructiveActionButton` in cancel sheets.
