Translucent white 5% card that stacks its children vertically, the standard container for settings groups, transaction detail lists, and label/value rows. `rowSpacing`, `padding`, and `radius` tune density; defaults are 16px gaps, 16x20 padding, 12px radius.

It provides chrome only: put `SettingsRow`s or plain label/value rows inside. For a captioned section use `TitledGlassRowCard` instead.
