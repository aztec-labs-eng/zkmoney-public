Amount-entry card for send/request flows: a liquid-glass role chip ("You send" / "Receive" / "Send" / "You request") with optional balance on top, then avatar + name/handle with the caller-supplied `amount` node at the trailing edge. Set `ringed` on the person for the current user's white story ring.

For two-party entry stack a `cornerStyle="top"` card above a `cornerStyle="bottom"` card with a 4px gap so the flattened corners form a seam; a standalone card uses the default `"all"`.
