Brand-gradient promo banner: leading `icon` (default "gift") + one-line `title`, with a darker CTA footer row (`ctaLabel` + chevron, wired to `onCta`). Pass `onDismiss` to show the ✕; promos should almost always be dismissible.

Slot between the balance header and the activity list on the home tab for growth/announcement moments ("Invite friends and earn up to $50."). One banner at a time; for permanent educational copy use `OnchainPrivacyBanner`.
